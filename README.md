# Bieżnia Weep EA200C

Strona do tworzenia własnych programów treningowych i sterowania bieżnią przez Bluetooth
(standard FTMS – moduł FitShow FS-BT-D2). Działa w przeglądarce, bez serwera i bez konta.

- **Mac / PC:** Chrome lub Edge (Safari nie obsługuje Web Bluetooth). Można zainstalować jako aplikację.
- **iPhone:** przeglądarka Bluefy.

Programy zapisują się w pamięci przeglądarki; kopię zrobisz w zakładce *Programy → Eksport*.
